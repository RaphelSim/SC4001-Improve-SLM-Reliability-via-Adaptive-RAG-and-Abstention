# Prompt templates

Research prompt wording is intentionally not finalized at foundation stage. When added, prompts are version-controlled text/template files with stable IDs and versions.

Reserved categories and example filenames:

- `sufficiency_assessment` — `sufficiency_v1.txt`
- `followup_query_generation` — `followup_query_v1.txt`
- `final_answer` — `final_answer_v1.txt`

See [prompt conventions](../documentation/09_prompt_conventions.md) before adding or changing a prompt.
