# Output guide

The current paragraph retrieval experiment, its three primary metrics, duplicate counting example, artifact schema and comparison interpretation are documented in [System architecture](SYSTEM_ARCHITECTURE.md). Copy-paste-ready commands and cache behaviour are in [Setup and run](SETUP_AND_RUN.md).

Historical `scripts/run_experiment.py` artifacts use the former answer/abstention `ExperimentRecord` and are retained for reproducibility. Their answer coverage, unsupported-answer and abstention metrics are not part of the new paragraph retrieval study. Do not mix historical answer results with `RetrievalStudyRecord` rows in a comparison.

The clean three-way Phase 3 comparison is `outputs/phase3-n100-seed88-top5-adaptive2x5-v4/`. Its `results.jsonl` contains all 100 Adaptive V2.1 attempts. Since 37 controller records ended in errors, use `three_way_comparison.json` to distinguish retrieval metrics over all 100 attempts from controller metrics over valid decisions and the common 63-question valid cohort. The comparison checks identical question IDs and order and reuses the saved Top-5 and Adaptive V1 results; it does not rerun either system. The earlier `v3` pilot is preserved but excluded because its prompt contained a sample-specific entity from the first question. See [Setup and run](SETUP_AND_RUN.md) for the exact V2.1 and comparison commands, and [System architecture](SYSTEM_ARCHITECTURE.md) for metric definitions and observed trade-offs.
